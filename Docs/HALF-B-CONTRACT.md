# Half B contract

Half B takes a finished **what** and lets a worker choose a **how**. The operator only checks whether the Prefer success held.

## Input (only)

- This row’s success sentence
- `behavior_keys`
- Refuses / `do_not_waive`
- Out-of-scope ids

## Output

Evidence those `behavior_keys` hold.

## Not inputs

Method, engine, scene path, folder layout (`Systems/`, `Core/`, …), or other project nouns. The harness must not encode one method.

## Dispatch

- Prefer names **no** `lane_id` / lane list → **exactly one** implementation seat.
- That seat is **not** looked up in a baked six-lane catalog. A project `lanes.yaml` with six ids does **not** mean fan-out when Prefer is silent.
- Multi-lane concert is opt-in only after one seat can be accepted or rejected without a prescribed method (later tip).

## Check

- Green handoff text contains the Prefer’s `behavior_keys` (loaded from the armed packet). No `keys_ok: true` stamp.
- When `engine.build_command` is empty: no `project.godot`, no csproj walk, no `dotnet`, no engine binary invent.
- Topology rewrite only when Prefer sets `topology_law: true`. Cites only when Prefer lists a non-empty `host_law_ids`. Words like `worldgen` / `occupancy` / `dual` and `prefer_authorship: true` do not arm bind.

## Prefer-align (before seat)

Fail-closed. Writes nothing. Prefer is source of truth.

- Empty `behavior_keys` → block.
- Host-law cite (incl. `locks.*.law_cite` / `prefer_law`) while `host_law_ids` empty → block.
- Topology arm only via `topology_law: true` (refuse names are not arms).
- Live runner **discovers** files under the write target and passes them as `observed_entries`. Empty `allowed_entries` + any discovered entry → block. No product scene names in the gate module.
- `factory-project.yaml` `game_repo_path` disagreeing with identity/Prefer → block.

## Ticket kinds (do not blur)

| Kind | Success text | Check | Operator F5 |
|------|--------------|-------|-------------|
| **Contract** | A function or file fact. No “point,” “see,” “GM,” or “board.” | Probe only (`behavior_key_checks`). | Do **not** ask. Probe pass closes the Prefer. |
| **Moment** | A thing you can point at or watch. | The **same** act, on a tiny board. | You look. No stamp without that. |

Roles (no name ban): **Gate A** = forms only (row bind, verbatim product job, `observe`↔`proof_shape`, catalog ids exist, no author hostile bits). **B₁** = harness second reader: runner `observe_class` must match map `observe` (`person`|`record`). **B₂** = harness transcript class must match; green stdout / `{key: true}` / author stamp is not a pass. Map column `Observe` is human-only; Ticketment copies it into `proof_shape` and does not shop the catalog.

## Prefer-named check

- Prefer must set `behavior_key_checks: { <behavior_key>: <probe_id> }` for every key, or leave checks empty and name the missing observer (empty → Gate A fail).
- Runner class comes from code path: window + pointer inject → `person`; stdout / file / command compare → `record`. Catalog keys cannot override. Renaming `entrypoint` to `argv` does nothing.
- Agent may implement the program under test. Agent may **not** write the pass bit (`map_fidelity_hostile` / `weld_intent_hostile` — harness only, `source: harness_b1` / `harness_b2`).
- A script that prints a constant, or echoes its point/selector argument, fails.
- Exit code alone (`command_exits_zero`) is **not** person-row evidence.
- Feedstock stays in Ticketment. B₂ does not re-open roadmaps to invent what feedstock wanted.

## Exit Success (one path)

After the agent, eat Success runs Prefer-named probes → harness transcript pack (`source: harness_b2`) → class must match map `observe`. Each key true only when **that** key’s probe passed **and** transcript class matches. Implementer `{key: true}` / agent `evidence_pack` / bare stamp fails. Empty binding / empty catalog → stay red. Do not write the B₂ stamp from the skill.
