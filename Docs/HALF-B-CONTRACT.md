# Half B contract

Half B takes a finished **what** and lets a worker choose a **how**. The operator only checks whether the Prefer success held.

## Input (only)

- This row’s success sentence
- `behavior_keys`
- Refuses / `do_not_waive`
- Out-of-scope ids

## Output

Evidence those `behavior_keys` hold.

## Not inputs

Method, engine, scene path, folder layout (`Systems/`, `Core/`, …), or other project nouns. The harness must not encode one method.

## Dispatch

- Prefer names **no** `lane_id` / lane list → **exactly one** implementation seat.
- That seat is **not** looked up in a baked six-lane catalog. A project `lanes.yaml` with six ids does **not** mean fan-out when Prefer is silent.
- Multi-lane concert is opt-in only after one seat can be accepted or rejected without a prescribed method (later tip).

## Check

- Green handoff text contains the Prefer’s `behavior_keys` (loaded from the armed packet). No `keys_ok: true` stamp.
- When `engine.build_command` is empty: no `project.godot`, no csproj walk, no `dotnet`, no engine binary invent.
- Topology rewrite only when Prefer sets `topology_law: true`. Cites only when Prefer lists a non-empty `host_law_ids`. Words like `worldgen` / `occupancy` / `dual` and `prefer_authorship: true` do not arm bind.

## Prefer-align (before seat)

Fail-closed. Writes nothing. Prefer is source of truth.

- Empty `behavior_keys` → block.
- Host-law cite (incl. `locks.*.law_cite` / `prefer_law`) while `host_law_ids` empty → block.
- Topology arm only via `topology_law: true` (refuse names are not arms).
- Live runner **discovers** files under the write target and passes them as `observed_entries`. Empty `allowed_entries` + any discovered entry → block. No product scene names in the gate module.
- `factory-project.yaml` `game_repo_path` disagreeing with identity/Prefer → block.

## Prefer-named check (contract how)

- Prefer must set `behavior_key_checks: { <behavior_key>: <probe_id> }` for every key. Silence → Prefer-align fail.
- Catalog probe for a behavior key is **operation + value to compare** (`entrypoint_result_equals`): runner invokes Prefer-named entrypoint and compares the result to catalog `equals`.
- Agent may implement the entrypoint. Agent may **not** write the expected value, the pass bit, or the program that decides pass.
- Exit code alone (`command_exits_zero`) is **not** behavior-key evidence.
- Feedstock stays in Ticketment. B₂ does not re-open roadmaps to invent what feedstock wanted.

## Exit Success (one path)

After the agent, eat Success runs Prefer-named probes → harness pack (`source: proof_catalog`) → `evaluate_behavior_evidence` only (`pass_basis: behavior`). Each key true only when **that** key’s probe passed. Implementer `{key: true}` / agent `evidence_pack` fails. Bare `weld_intent_hostile_ok` stamp fails. Empty binding / empty catalog / wrong op → stay red. Do not write the B₂ stamp from the eat.

## Tip claim

This tip proves the check. It does **not** GREENLIGHT, weld, or claim a welded product.
