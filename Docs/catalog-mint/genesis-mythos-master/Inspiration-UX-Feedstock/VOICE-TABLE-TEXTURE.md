## Job

The table can hear who is speaking. The system transforms the live voice. The DM still writes and speaks the NPC. Players may optionally mark IC.

---

## Locked brief (2026-08-11)

| Job | Pattern |
|-----|---------|
| **NPC voice (DM)** | Set of waveforms that can be freely manipulated on the fly. Quick one-offs: improvise or use default. Recurring characters: tune the changer to the desired sound and save it to that NPC; when the DM speaks for that NPC the tuned voice is applied. |
| **Player character voice** | Players set their character’s voice the same way. Intentional “speak in character” button (or equivalent signal) activates it. Optional, never mandatory. |
| **Defaults and speed** | Default voice always available. No requirement to configure anything for a throwaway line. Manipulation surface must stay fast enough for live table use. |
| **Possession note** | When the DM possesses an NPC in World-cam, the saved voice profile for that actor should ideally auto-apply or be one click away. Consistent with skeleton-key posture. |
| **Boundary** | DM remains the author of NPC speech. System supplies the voice transform; it does not invent dialogue or replace the DM. Lives under collaborative table agency and roleplay. Not a product voice-acting mandate. |
