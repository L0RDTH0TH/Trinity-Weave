# Class-expression board — Cursor draft v3

**Role:** Player-facing texture for `class-unique-expression-surfaces`. Pattern language only. **Not locked** — Grok+User validate. Pin gate remains **open**. Not applied seasoning.

**Scope:** SRD 5.1 major classes + Artificer. Key divergent subclasses. Shared surfaces: Tools, Languages, **Inventory**.

**Supersedes v2** on: capacity (thin base / subclass-primary), continuous-care (now subclass desks), inventory (new), murderhobo config, fixed primary direction.

---

## Locked method (v2 stands + v3)

| Rule | Lock |
|------|------|
| **Pattern-learning north star** | Mini-games teach real-world-adjacent patterns under fantasy skin. Goals: fill downtime + make the world feel more mechanical / less handwavy. Soft-teaching is **mostly the loop itself**. |
| **Universal skip** | Skip = system performs the action **as if the player did it**. Near-average most of the time; occasional real-bad possible but not default. Manual = better / more coherent / lower-cost. **Never a hard gate.** |
| **Murderhobo mode** | DM-set config; prefer **campaign** scope (same world, different tables). When on: every expression desk, continuous-care, inventory, and related soft loops auto-resolve at skip quality. **Players never see the desks.** World / NPC systems still run. Never a hard gate or soft-shame tax. |
| **Capacity** | **Thin base-class** = secondary precursor (“the pattern has begun to take root”). Grows slowly/generically with level + any coherent stress. **Subclass** = **primary** growth surface — owns the concrete Sense → Play → Outcome desk. Subclass is the identity engine; base keeps the shared pattern. |
| **Primary direction** | Class + subclass set a **fixed** primary direction (part of their nature). Stereotype + subclass express *how* it is felt. Optional secondary lean ok. **No fluid / player-swappable lean** mid-play. |
| **Combat interrupt** | Expression desks **yield to initiative**. Mini-game does **not** interrupt combat; combat **can** interrupt mini-game. |
| **Stereotype lens** | Productive exaggeration. Watch cartoonish / culturally lazy collapse. |
| **Class → subclass** | Base owns core pattern/field. Subclass = different expression / material / cost surface of the **same** pattern — **and** seats the primary capacity desk. |
| **Hyper-fit** | Extract job/pattern only — never wholesale steal a reference loop. |

**Assigned thematic target on skip (still light):** default = stay inside subclass flavor. Optional short intent before skip; auto-resolve *may* hit it. Not a second desk.

**Out of scope this draft:** economy surface; full magic-item desk. Legendary distinction noted only (below).

## Murderhobo mode

- **Who sets it:** DM. Prefer campaign-scoped config so two tables on the same world can disagree.
- **When on:** players never see expression desks, inventory desk, or related soft loops. Those surfaces auto-resolve at universal-skip quality (near-average; occasional real-bad still possible).
- **What still runs:** world / NPC labor, critical nodes, knowledge flow, ecology, and any NPC who *does* use these desks.
- **Refuse:** treating murderhobo as a shame tax, XP penalty, or “you’re playing wrong.” It is a first-class table config.

## Shared non-class surfaces

### Tools

Short proficiency loops (repair, craft, open, measure). Classes may specialize. Same skip + murderhobo. Not a class-owned desk.

### Languages

Learn / decipher / perform short exchanges. Soft-teaching literacy. Never hard-blocks quests. Same skip + murderhobo.

### Inventory — full grain (new)

**Job / pattern:** **constraint + load + provenance + maintenance** under a living world.

**Not:** bag-tetris · pure weight punishment · a second character sheet · class-owned identity desk.

**Who owns it:** shared surface. Classes may specialize (Artificer infusions, Rogue tool rolls, Ranger kit marks) without owning the core desk.

1. **Stereotype (table, not class):** You are a person with limited hands, a pack that remembers, and gear that has a history — not a walking vault.
2. **Field / domain:** Slots / bind points · bulk & awkwardness · wear · **provenance** (who made it, who claimed it, which node it is bound to) · repair / oil / dry / ward.
3. **Sense:** Readable tells on what you carry — strain on the body, straps cutting, a blade dulling, a relic *humming toward its node*, a stolen seal still warm, food going over. Murderhobo: players do not see this desk; tells still exist in the world for NPCs / DM.
4. **Play:** Pack, bind, discard, consign, repair, mark provenance, separate “claimed by a node” from “yours.” Hands: rearrange under constraint, choose what to maintain, choose what to let degrade. Short loop. Combat yields this desk.
5. **Outcome:** Coherent kit (ready, provenanced, maintained) **or** strain / loss / broken provenance / item claimed back by a node. Manual = tighter constraint solutions, lower loss, clearer provenance. Skip = near-average pack; rare real-bad (lost strap, spoiled ration, provenance smear).
6. **Pattern taught:** Living with limits + history of things — not tetris, not a spreadsheet of pounds.
7. **Class specialization (does not own the desk):** Artificer → infused pieces want maintenance; Wizard → maps/scrolls are fragile provenance; Ranger → hunt kit + companion load; Rogue → conceal / ditch; Paladin → sworn gear on the oath ledger.
8. **Refuse:** Inventory-as-punishment-only; mandatory nightly tetris; cloning a specific loot-manager; making inventory the Fighter’s “real” class desk; legendary-item full desk here.
9. **Skip / murderhobo:** Universal skip. Murderhobo hides the desk entirely; world still tracks load/provenance/wear for simulation.

**Legendary items (light lock — not a desk this pass)**

| Kind | Meaning |
|------|---------|
| Legendary-by-rarity / singularity | One-of or extremely limited; usually bound to an **essential node**. Heavier provenance / critical-node weight. |
| Legendary-by-power | High impact, not unique in principle (Staff-of-the-Magi class). |

Both are magic items. Full item desk **deferred**. Economy surface **deferred**.

## Artificer

**Primary direction (fixed):** Bind weave into objects that must survive the world.  
**Thin base precursor:** “Rules can live in things.” Grows slowly with level + any coherent making/stress. Not the identity desk.

**Stereotype:** Gadgeteer who solves the world by inventing, tuning, and field-testing.  
**Pattern taught:** Network / infrastructure / tolerance under load.  
**Refuse:** Factory-sim wholesale; mandatory craft wall; potion-sim clone; “not a wizard.”

### Subclass-primary desk — commission / material / role chain (full grain)

Every Artificer subclass seats the **same chain** in different material. The **base piece** (the thing that must survive) is the object of the desk.

1. **Sense:** Commission brief — what role must this piece play in the world (dose, turret, construct, suit)? What materials exist (bought, scavenged, node-bound)? Where will it fail first?
2. **Play:** Source → shape → bind weave into the object → field-test under the role’s stress. Hands: pick a commission, commit materials, set tolerances, run the test, scrap or lock.
3. **Outcome:** A piece that holds its role, or a readable failure (wrong material, weak bind, role mismatch). Manual = coherent on-theme piece, lower scrap. Skip = near-average piece; rare real-bad (misfire).
4. **Subclass material (same chain):**
   - **Alchemist** — commission = dose / reaction; materials = reagents; role = timing + effect; failure = bad batch.
   - **Artillerist** — commission = field engine; materials = housing + charge; role = placement + calibration.
   - **Battle Smith** — commission = companion construct; materials = frame + loadout; role = survive beside you (continuous; skip/murderhobo still apply).
   - **Armorer** — commission = suit; materials = plates; role = mode integrity on a body.
5. **Skip / murderhobo:** Universal skip on the chain. Murderhobo: no commission desk; world/NPC artificers still make things.

## Barbarian

**Primary direction (fixed):** Ancestral / inner-storm contact.  
**Thin base precursor:** The storm has begun to take root — a generic stoke/cool that grows slowly with level + any coherent violence/stress. Not the identity desk.

**Stereotype:** Force of nature who *becomes* the fight.  
**Pattern taught:** Charge / recovery / overheat inside a live inner weather.  
**Refuse:** Rage as only a combat toggle; “dumb brute” as the whole identity.

### Subclass-primary — Totem / Wild Heart (full grain): spirit-path journey

1. **Sense:** Which spirit-path is open after recent stress (hunt, blood, oath-break, wilderness night)? Totem pressure as weather on the inner storm — animal presence, not a menu pet.
2. **Play:** Walk a short spirit-path (offer, follow, bargain, refuse). Hands: choose a path token, endure a beat of the journey, take or reject the bargain. Secondary lean may be social (the spirit’s ask) without swapping primary direction.
3. **Outcome:** A seated totem posture (next-fight / next-travel tell) **or** a refused/sour path. Manual = on-theme spirit, cleaner bargain. Skip = near-average totem; rare real-bad (wrong spirit, lingering debt).
4. **Pattern taught:** Relationship with a living other inside the storm — not a buff icon.
5. **Refuse:** Spirit as fashion skin; culturally lazy “totem animal picker.”

### Subclass-primary — Berserker (full grain): wave / mental arena

1. **Sense:** The next wave’s height after recent stress — how hard the storm wants to come in. Arena = inner space where you meet the wave, not a second overworld.
2. **Play:** Ride or cut the wave in a short mental arena (hold, break, redirect). Hands: commit to a ride, bleed heat, choose crash vs channel.
3. **Outcome:** A usable next-fight posture (clean ride / controlled crash) **or** leftover arena noise. Manual = coherent ride, lower crash tax. Skip = near-average stoke; rare real-bad (you come out wrong).
4. **Pattern taught:** Meeting a surge you cannot turn off — surfing, not homework.
5. **Refuse:** QTE-only identity; “mindless” as the only Berserker fantasy.

### Other subclass desks (same storm, shorter note)

- **Ancestral Guardian** — call / placate ancestor chorus (journey-shaped like Totem, chorus instead of animal path).
- **Zealot** — vow brands & sacred pain ledger (arena-adjacent; pain as the wave’s material).

## Cleric

**Thin base precursor:** A channel has begun to take root — generic omen clarity grows slowly with level + any coherent rite/stress.

**Stereotype:** Living radio to a god; faith with paperwork and miracles.

## Druid

**Primary direction (fixed):** Nature-aligned always.  
**Thin base precursor:** Living systems begin to answer — generic grove-sense grows slowly with level + any coherent wild stress.

**Stereotype:** Gardener of living systems.  
**Pattern taught:** Stewardship / succession.  
**Refuse:** Farm-sim wholesale; mandatory chore wall; “tree-hugger” flatten.

### Subclass-primary — Circle (full grain): localized terraforming / succession

Applies to Land / Spores / Shepherd / Stars as **material** on the same desk. Moon leans the same desk toward form-succession (which shapes the land will accept in you).

1. **Sense:** What the local patch wants next after recent stress (drought, blood, spore bloom, flock gap, star-season). Readable succession: what dies if ignored, what colonizes if helped.
2. **Play:** Localized terraforming — plant, prune, flood, burn, inoculate, relocate a species, open a corridor. Hands: place succession tokens on a small patch, set one season’s orders, watch the tick. Not a planet editor.
3. **Outcome:** A patch with a new succession state + a boon/affinity **or** blight / runaway colonizer. Manual = on-theme Circle result (Land = plants, Spores = rot cycle, Shepherd = flock, Stars = sky-garden). Skip = near-average patch; rare real-bad (blight).
4. **Pattern taught:** Succession ecology in a bounded place.
5. **Refuse:** Global terraforming homework; Stardew clone; Circle as only a spell list.

## Fighter

**Primary direction (fixed):** Practice of applied violence + kit.  
**Thin base precursor:** The craft has begun to take root — generic drill grade grows slowly with level + any coherent fight/stress.

**Stereotype:** Professional of violence.  
**Pattern taught:** Deliberate practice + kit systems.  
**Refuse:** “Fighter has no fantasy”; collapsing into Monk’s self-tuning desk; fighting-game clone.

### Timed-form grain (shared *shape* with Monk; different job)

1. **Sense:** Where the last fight wore the **kit** and the **form** — dull edge, bad stance habit, a maneuver that didn’t land.
2. **Play:** Short timed form strip (stance → window → commitment) **plus** kit swap / spar notes. Hands: hit the windows, change a piece of kit, mark one maneuver. This is **applied violence**, not breath-as-self.
3. **Outcome:** Refreshed maneuver + kit posture **or** sloppy form leftover. Manual = sharper, lower wear. Skip = near-average stock grade; rare real-bad (kit mismatch).
4. **Subclass-primary material:** Champion = form perfection; Battle Master = maneuver recipes; Eldritch Knight = weapon+cantrip weave; Arcane Archer = shot-arc; Cavalier = mount/guard pair.

**Stereotype:** Flesh turned into technique.  
**Pattern taught:** Self-regulation / embodied practice.

4. **Subclass-primary material:** Open Hand = redirect; Shadow = silence form; Four Elements = elemental overlay; Mercy = pressure map; Astral Self = limb calibration.

## Ranger

**Primary direction (fixed):** Nature-aligned always.  
**Thin base precursor:** Land and quarry begin to read — generic hunt-sense grows slowly with level + any coherent travel/stress.

**Stereotype:** Edge-walker; maps, marks, bond.  
**Pattern taught:** Tracking / route / bond.  
**Refuse:** Pet-as-gate; single iconic-hero flatten; survival-sim homework.

### Subclass-primary — Beast Master (full grain): side-quest hunt + companion care

1. **Sense:** What the land and the bond need after recent stress — a quarry worth a short hunt, a companion tell (hunger, injury, distrust, eagerness). Hunt and care are one desk.
2. **Play:** Run a **side-quest-scale** hunt (mark → route → strike or release) **and** tend the companion (feed, rest, loadout, trust). Hands: place marks, walk a short route, resolve the quarry, spend a care beat. Not a second campaign.
3. **Outcome:** Meat/hide/info + a coherent bond state **or** a sour hunt / neglected companion. Manual = on-theme pair, healthier bond. Skip = near-average hunt+care; rare real-bad (lost companion trust, botched quarry).
4. **Pattern taught:** Working with a living partner inside a living land.
5. **Refuse:** Compulsory pet micromanagement as a wall; hunt as full second adventure spine.

### Other subclass desks (same hunt-board pattern)

Hunter = quarry specialization; Gloom = first-strike/underdark marks; Horizon = planar trails; Fey = bargain/mist marks. Each is the primary capacity desk in that material.

## Sorcerer

**Primary direction (fixed):** Move *with* the weave; body is the vessel.  
**Thin base precursor:** The vessel begins to hold live current — generic reach grows slowly with level + any coherent magical stress. Ceiling still grows via level + repeated adventure (in-fiction spell-list / power).

**Fantasy / stereotype:** Native to body *and* world. Path of least resistance; artistic twist/bend. Contrast Wizard: tames, maps, brutalist.

**Subclass-primary desk — weave-atelier** (v2 structure; now explicitly **subclass-seated**):

1. **Sense:** Ambient pressure / events; **subclass-tinted region** of the weave; higher level = deeper/subtler.
2. **Play:** At reachable depth, bend/twist live current; read stability and emergence.
3. **Outcome:** Bank, reinforce, or abort a personal pattern. Manual = on-theme (storm → lightning-native). Skip = near-average; *may* hit assigned thematic target; rare real-bad if depth was high.
4. **Subclass leverage:** Native region, preferred bends, vessel feedback, ambient tells — not particle color. Draconic / Wild / Storm / Shadow / Divine Soul / Clockwork = regions of the same atelier.
5. **Cross-class:** May externalize a clean pattern into a scroll/map for a wizard (transcription consumes the map).
6. **Refuse:** Wizard book clone; skip as gate; vessel limit as menu unlock with no stress.
7. **Skip / murderhobo:** Universal. Murderhobo: no atelier UI; vessel still grows near-average in the world.
