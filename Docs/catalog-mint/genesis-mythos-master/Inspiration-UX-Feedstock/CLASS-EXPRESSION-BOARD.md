# Class-expression board — Cursor draft v2

**Role:** Player-facing texture for `class-unique-expression-surfaces`. Pattern language only. **Not locked** — Grok+User validate. Pin gate remains **open**.

**Scope:** SRD 5.1 major classes + Artificer. Key divergent subclasses only.

## Locked method

| Rule | Lock |
|------|------|
| **Pattern-learning north star** | Mini-games teach real-world-adjacent patterns under fantasy skin (e.g. network/infrastructure thinking without naming the reference). Primary goals: fill downtime + make the world feel more mechanical / less handwavy. Soft-teaching is **mostly the loop itself**. |
| **Universal skip** | Skip = system performs the action in the background **as if the player did it**. Lands **near-average most of the time**; occasional real-bad possible but not the default. Manual play produces better / more coherent / lower-cost results. **Never a hard gate.** |
| **Pillars** | Loops may lean Roleplay, Exploration, or Combat as needed. Hard rule: mini-game does **not** interrupt combat; combat **can** interrupt mini-game. |
| **Stereotype lens** | Productive exaggeration that makes the class feel itself. Watch cartoonish / culturally lazy collapse. |
| **Class → subclass** | Base owns core pattern/field. Subclass = different expression / material / cost surface of the **same** pattern. |
| **Hyper-fit** | Extract job/pattern only — never wholesale steal a reference loop. |

## Universal skip (apply to every row)

Including continuous-care rows (Druid grove, Ranger companion, Paladin oath, Warlock debt, Cleric flock/parish): auto-resolve near-average most of the time; rare real-bad; manual attention still worthwhile for quality/control.

**Assigned thematic target on skip (light proposal):** default = stay inside subclass flavor. Optional: player may set a short intent before skip; auto-resolve *may* hit that target, still near-average, still can go real-bad if depth/risk was high. Keep the control tiny — not a second desk.

## Shared non-class surfaces

| Surface | Pattern job | Note |
|---------|-------------|------|
| Tools | Short proficiency loops (repair, craft, open, measure) | Class may specialize; same skip rule |
| Languages | Learn / decipher / perform short exchanges | Soft-teaching literacy; never hard-blocks quests |

## Revised contrasts (replace earlier hard splits)

| Pair | Revised contrast |
|------|------------------|
| **Wizard vs Artificer** | Same family (both work the weave). Wizard = external theory / rewrite rules into book (domineering, map-and-transcription). Artificer = bind rules into objects that must survive the world (schematic, tolerances, field test). Different desk and failure texture — not “wizard vs not-wizard.” Artificers are technically wizards in an important sense. |
| **Wizard vs Sorcerer** | Wizard tames the weave — refuses it an inch of the self; efficient/brutalist; external maps. Sorcerer moves *with* the weave — path of least resistance; artistic twist/bend; body as vessel. Scrolls = maps of the weave; wizard transcription consumes the map. Sorcerer does not need the map (works from inside the current) but may optionally externalize a clean pattern into a scroll/map for a wizard. |
| **Cleric vs Paladin** | Both can have institutional homes (temples, orders, chapters, war-shrines). Desk: Cleric tends the living channel / tradition / domain practice (**serves it**). Paladin tends their own sworn word as the primary ledger (**order is context/support**). Institutional vs personal *account* — not “one has church, one doesn’t.” |
| **Fighter vs Monk** | Shared: short timed form practice. Fighter = professional craft of **applied violence and kit** (maneuvers, loadout, sparring). Monk = **body as primary instrument** (breath, ki cadence, self-tuning). Craft of violence vs craft of the self. |

## Artificer

1. **Stereotype:** Gadgeteer who solves the world by inventing, tuning, and field-testing devices — “wait, I can build that.”
2. **Field / domain:** Workshop · schematics · reagents · prototypes · infusion slots. **Family:** weave-worker (object-bound).
3. **Loop texture:** Place/adjust components on a schematic → test under stress → lock infusion or scrap. Hands: drag parts, set tolerances, fire a bench test. Failure = object does not survive the world.
4. **Pattern taught:** Network / infrastructure / tolerance thinking — systems that must hold together under load. (Fantasy skin; do not name or clone the reference factory.)
5. **Subclass variants (same “bind rules into surviving objects” pattern):**
   - Alchemist → vials / reactions / dose timing
   - Artillerist → turret / field engine placement & calibration
   - Battle Smith → companion construct care & loadout (continuous-care; universal skip)
   - Armorer → suit plates / mode swaps / integrity
6. **Refuse:** Wholesale factory-sim homework; mandatory crafting wall; potion-sim clone; pretending Artificer is “not a wizard.”
7. **Soft-teaching:** The bench test *is* the lesson — which tolerance blew, why the object failed.
8. **Skip:** Universal skip. Near-average infusion most of the time; rare real-bad (misfire / scrap). Manual = tighter tolerances, lower cost, more coherent device.

## Barbarian

1. **Stereotype:** Force of nature who *becomes* the fight — rage as weather you call, not a button you forget.
2. **Field / domain:** Breath · heart · totem / ancestral pressure · aftermath.
3. **Loop texture:** Between fights / camp: tend the rage-cycle (stoke, cool, brand marks) → choose next trigger posture. Hands: hold breath bar, carve totem marks, choose cool-down path. **Pillar lean:** Combat + Roleplay downtime.
4. **Pattern taught:** Charge / recovery / overheat — managing a volatile resource you live inside.
5. **Subclass variants (same “tend the inner storm” pattern):**
   - Berserker → pure burn / reckless stoke
   - Totem / Wild Heart → animal spirit bargains & offerings
   - Ancestral Guardian → call / placate ancestor chorus
   - Zealot → vow brands & sacred pain ledger
6. **Refuse:** Rage as only a combat toggle; “dumb brute” lazy caricature as the whole identity.
7. **Soft-teaching:** Overstoke shows on next-fight preview; the cycle itself teaches the cost of going too hot.
8. **Skip:** Universal skip. Near-average stoke; rare real-bad (wrong posture / crash). Manual = cleaner recovery, better trigger.

## Bard

1. **Stereotype:** Social physicist — words, songs, and scenes bend rooms; the party’s spotlight director.
2. **Field / domain:** Repertoire · audience heat · motifs · patronage.
3. **Loop texture:** Compose / rehearse a short motif → preview audience heat → bank for later scene. Hands: place beats, tag emotion, cut length. **Pillar lean:** Roleplay.
4. **Pattern taught:** Audience / feedback loops — read a room, adjust signal, bank what lands.
5. **Subclass variants (same “shape a room with performance” pattern):**
   - Lore → cutting word / knowledge riff library
   - Valor / Swords → martial flourish choreography
   - Glamour → courtly glamour / dream-audience
   - Whispers → secret / fear motif bank
   - Creation → temporary prop / set-piece conjure
6. **Refuse:** Mandatory karaoke homework; endless dialogue trees as the only loop; “horny lute guy” flatten.
7. **Soft-teaching:** Audience heat *is* the lesson — which beat landed, which dropped the room.
8. **Skip:** Universal skip. Near-average stock motif; rare real-bad (wrong room). Manual = tighter heat, cheaper social cost.

## Cleric

1. **Stereotype:** Living radio to a god — rites, omens, and parish pressure; faith with paperwork and miracles.
2. **Field / domain:** Altar · liturgy · omen board · flock / tradition. **Account:** institutional / living channel you *serve*. May have temple/order/war-shrine home — same as Paladin can.
3. **Loop texture:** Prepare rites on an altar grid → read omen clarity → commit channel. Hands: slot prayers, weigh offerings, clear corruption. Continuous-care: flock/parish (universal skip).
4. **Pattern taught:** Protocol / tradition maintenance — keep a living channel coherent; read mismatch as omen.
5. **Subclass variants (same “tend the divine channel / domain practice” pattern):**
   - Life → healing / flock vitality ledger
   - War → battle-bless / banner rites
   - Knowledge → scriptorium / omen catalog
   - Trickery → mask / misdirection rites
   - Nature → seasonal / rural parish rites
   - Death / Grave → boundary / funeral / undead pressure
6. **Refuse:** Pure spell menu with no rite desk; cultural-lazy “generic priest”; mandatory daily mass as a gate; “Cleric has church, Paladin doesn’t.”
7. **Soft-teaching:** Blurry vs clear omen *is* the lesson — which offering mismatched the domain.
8. **Skip:** Universal skip (includes parish care). Near-average rite; rare real-bad (omen sour / flock slip). Manual = clearer channel, lower tithe/cost.

## Druid

1. **Stereotype:** Gardener of living systems — the land is a patient you tend, not scenery.
2. **Field / domain:** Grove / circle plot · seasons · symbiotic stock · wildshape affinity.
3. **Loop texture:** Tend a living plot → season tick → harvest boon / wildshape affinity. Hands: place flora/fauna tokens, set care orders, watch growth. **Pillar lean:** Exploration + Roleplay. Continuous-care grove (universal skip).
4. **Pattern taught:** Living-system stewardship — inputs, seasons, succession, readable wilt vs health.
5. **Subclass variants (same “tend a living system” pattern):**
   - Circle of the Land → plants / biome plots
   - Circle of Spores → fungi / spore beds / rot cycle
   - Circle of the Moon → wildshape form care / apex forms
   - Circle of Stars → constellation garden / omen sky
   - Shepherd → beast spirits / flock
6. **Refuse:** Farm-sim wholesale; mandatory chore wall; “tree-hugger” flatten.
7. **Soft-teaching:** Wilt / bloom *is* the lesson; healthy plot unlocks clearer habitat reads in the world.
8. **Skip:** Universal skip. Near-average grove; rare real-bad (blight / lost affinity). Manual = better harvest, tighter wildshape fit.

## Fighter

1. **Stereotype:** Professional of violence — drills, forms, kit, and the craft of not dying stupid.
2. **Field / domain:** Drill yard · maneuver cards · kit loadout · sparring ledger.
3. **Loop texture:** Short timed form (stance → timing windows → commitment) → grade → unlock/refresh maneuvers. Hands: time inputs on a form strip, swap kit, mark spar notes. Shared *shape* with Monk (timed form); **job** = applied violence + kit.
4. **Pattern taught:** Deliberate practice / kit systems — rehearsed violence as a trade, not a mood.
5. **Subclass variants (same “drill the craft of fighting” pattern):**
   - Champion → pure form perfection / crit craft
   - Battle Master → maneuver recipe book
   - Eldritch Knight → weapon+cantrip weave drills
   - Arcane Archer → shot-arc practice / arrow recipes
   - Cavalier → mount/guard drill pairs
6. **Refuse:** Endless rhythm-hell as identity; “fighter has no fantasy”; full fighting-game clone; collapsing into Monk’s self-tuning desk.
7. **Soft-teaching:** Missed window highlights which beat; clean drill tags the maneuver that unlocked.
8. **Skip:** Universal skip. Near-average stock grade; rare real-bad (sloppy form / kit mismatch). Manual = sharper maneuvers, lower wear.

## Monk

1. **Stereotype:** Body as instrument — breath, forms, and discipline that turns flesh into technique.
2. **Field / domain:** Forms · ki pool cadence · monastery vows · pressure points.
3. **Loop texture:** Short timed kata (breath sync + strike sequence) → ki cadence → bank focus. Hands: follow form ghost, match breath pulses, choose vow emphasis. Shared *shape* with Fighter (timed form); **job** = craft of the self.
4. **Pattern taught:** Self-regulation / embodied practice — instrument tuning, not kit loadout.
5. **Subclass variants (same “tune the body-instrument” pattern):**
   - Open Hand → pure form / redirect
   - Shadow → silence / smoke form variants
   - Four Elements → elemental kata overlays
   - Mercy → pressure-point heal/harm map
   - Astral Self → astral limb calibration
6. **Refuse:** QTEs as only identity; orientalism-as-product; mandatory meditation wall; collapsing into Fighter’s kit/maneuver desk.
7. **Soft-teaching:** Desync shows which beat broke; clean kata brightens ki cues — the body *is* the feedback.
8. **Skip:** Universal skip. Near-average cadence; rare real-bad (cold body / broken form). Manual = cleaner ki, lower strain.

## Paladin

1. **Stereotype:** Walking oath — promises with teeth; aura and judgment you can feel in the room.
2. **Field / domain:** Oath ledger · tenets · aura tuning · sacred gear vows. **Account:** personal sworn word is primary; order/temple/chapter is context/support (may still have an institutional home).
3. **Loop texture:** Review oath ledger (tenet stress, breaks, amends) → tune aura → seal or atone. Hands: weigh tenet tokens, assign amends, set aura posture. Continuous-care oath (universal skip).
4. **Pattern taught:** Commitment / integrity accounting — a personal ledger with readable stress and repair.
5. **Subclass variants (same “live the oath ledger” pattern):**
   - Devotion → purity / honesty ledger
   - Ancients → light-vs-shadow / joy tenets
   - Vengeance → quarry / hunt oath
   - Conquest → dread / order aura
   - Redemption → spare / convert amend paths
6. **Refuse:** Lawful-stupid as only path; mandatory sermon homework; oath as pure buff menu; “Paladin has no church.”
7. **Soft-teaching:** Tenet stress *is* the lesson — which vow cracked; amend path shows the repair.
8. **Skip:** Universal skip. Near-average aura/ledger; rare real-bad (break / sour aura). Manual = tighter tenets, cheaper atonement.

## Sorcerer

**Leading structural upgrade (v2).**

1. **Stereotype / fantasy:** Magic is native to the body *and* the world. The sorcerer moves **with** the weave — path of least resistance, artistic expression, free-flowing twist/bend. Contrast Wizard: tames the weave, domineering, refuses it an inch of the self, efficient/brutalist, external maps.
2. **Field / domain:** Live current · vessel (the body) · ambient pressure · personal pattern bank. **Vessel limit:** capacity for patterns and strength of magic grows through level and repeated stress/adventure — this is the in-fiction spell-list / power ceiling.
3. **Loop texture — weave-atelier:**
   - **Sense:** ambient magic pressure / events; subclass-tinted; higher level = deeper/subtler signals.
   - **Play:** at reachable depth, apply bends/twists on live current; read stability and emergent behavior.
   - **Outcome:** bank a coherent personal pattern, reinforce one, or abort.
   - **Level:** deeper reach and greater vessel capacity.
   - **Quality:** manual play reliably produces on-theme / coherent results (e.g. storm → lightning-native shapes). Auto-resolve near-average; *may* hit an assigned thematic target. Occasional real-bad if depth is pushed hard.
   - **Cross-class hook:** sorcerer may optionally externalize a clean pattern into a scroll/map for a wizard (scrolls = maps of the weave; wizard transcription consumes the map). Sorcerer does not require the map — they work from inside the current.
4. **Pattern taught:** Exploratory search / pressure-and-pathway work inside a live system. Probe under constraint; read feedback; keep what stabilizes in the vessel.
5. **Subclass leverage (same “move with live current” pattern):** change **native region** of the weave, preferred bends, vessel feedback flavor, and ambient tells — not just particle color.
   - Draconic → elemental region / breath-current
   - Wild Magic → unstable region; learn to surf emergence (not “random screw you” as the only identity)
   - Storm → weather/lightning-native pathways
   - Shadow · Divine Soul · Clockwork → void / grace / order regions of the same atelier
6. **Refuse:** Wizard spellbook clone; homework maps as the sorcerer’s desk; anime-beam spam as the whole loop; skip as a gate; treating vessel limit as a menu unlock with no stress/adventure.
7. **Soft-teaching:** Stability / blowback *is* the lesson — the live current teaches what held. Soft-teaching is mostly the loop itself.
8. **Skip:** Universal skip. Near-average banked pattern most of the time; *may* land an assigned thematic target (player-set intent before skip, or stay inside subclass flavor — keep this control light). Occasional real-bad if depth was high. Manual = more coherent on-theme patterns, lower vessel strain.

## Wizard

1. **Stereotype:** Scholar who **tames** the weave — books, labs, careful theft of the universe’s rules. Domineering; refuses the weave an inch of the self; efficient / brutalist; external maps.
2. **Field / domain:** Spellbook · lab bench · copy/transcription · theory board. **Family:** weave-worker (map-and-rewrite). Local lore: scrolls = maps of the weave; transcription **burns the map into the book**.
3. **Loop texture:** Align field nodes on an external map → transcribe/copy → stress-test. Hands: balance nodes, ink glyphs, slot reagents, confirm copy. May receive a sorcerer’s externalized pattern-as-scroll.
4. **Pattern taught:** External modeling / rule-rewrite — map a system, then impose the map. (Different desk from Artificer’s “will this object survive?”)
5. **Subclass variants (same “study & rewrite the weave” pattern):**
   - Evocation → raw energy field shapes
   - Abjuration → ward lattices
   - Divination → omen / portents board
   - Necromancy → boundary / thrall notes (stereotype watch)
   - Illusion → sensory falsework
   - Bladesinging → form+spell weave (martial-scholar)
6. **Refuse:** Homework spreadsheet as the fun; copying Sorcerer’s *inside-the-current* atelier; stealing a specific puzzle game wholesale; pretending Artificer is outside the wizard family.
7. **Soft-teaching:** Unbalanced map *is* the lesson — which node drifted; clean balance unlocks the spell’s readable “why.”
8. **Skip:** Universal skip. Near-average stock copy; rare real-bad (botched transcription). Manual = cleaner map, lower reagent/scribe cost. Consuming a scroll/map is still a world event (the map is spent).
