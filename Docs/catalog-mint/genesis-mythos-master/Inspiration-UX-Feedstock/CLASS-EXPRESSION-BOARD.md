# Class-expression board — Cursor draft v1

**Role:** First-pass player-facing texture for `class-unique-expression-surfaces`. Pattern language only. **Not locked** — Grok+User validate for distinctness, stereotype lens, hyper-fit, skip-friendliness, subclass-as-same-pattern.

**Scope:** SRD 5.1 major classes + Artificer (common table expectation). Key divergent subclasses only (not every official subclass).

## Locked method (this draft)

| Rule | Lock |
|------|------|
| Stereotype lens | Iconic/memable stereotype as generative start; productive exaggeration; watch cartoonish / culturally lazy collapse |
| Hyper-fit | Extract job/pattern only — never wholesale steal a reference loop |
| Skip / frequency | Short loops; optional skip at gold / time / quality / difficulty; never a gate |
| Class → subclass | Base owns core pattern/field; subclass = different expression of same pattern |
| Combat vs loop | Mini-game does **not** interrupt combat; combat **does** interrupt mini-game |
| Soft-teaching | Explicit how a new player discovers and improves inside the loop |

## Shared non-class surfaces (brief)

| Surface | Pattern job | Note |
|---------|-------------|------|
| Tools | Short proficiency loops (repair, craft, open, measure) | Class may specialize; tools stay skippable |
| Languages | Learn / decipher / perform short exchanges | Soft-teaching literacy; never blocks quests hard |

## Artificer

1. **Stereotype:** Gadgeteer who solves the world by inventing, tuning, and field-testing devices — “wait, I can build that.”
2. **Field / domain:** Workshop · schematics · reagents · prototypes · infusion slots.
3. **Loop texture:** Place/adjust components on a schematic board → test under stress meter → lock infusion or scrap for parts. Hands: drag parts, set tolerances, fire a bench test.
4. **Subclass variants (same “build & bind tools” pattern):**
   - Alchemist → vials / reactions / dose timing
   - Artillerist — turret / field engine placement & calibration
   - Battle Smith — companion construct care & loadout
   - Armorer — suit plates / mode swaps / integrity
5. **Refuse:** Full Factorio factory homework; mandatory crafting wall; stealing a specific potion-sim wholesale.
6. **Soft-teaching:** Fail a test → read which tolerance blew → unlock simpler presets; success flashes the “why.”
7. **Skip:** Auto-craft at gold + time + quality floor; higher difficulty if rushed.

## Barbarian

1. **Stereotype:** Force of nature who *becomes* the fight — rage as weather you call, not a button you forget.
2. **Field / domain:** Breath · heart · totem / ancestral pressure · aftermath.
3. **Loop texture:** Between fights / at camp: tend the rage-cycle (stoke, cool, brand marks) → choose next trigger posture. In quiet: ritual stoke. Hands: hold breath bar, carve totem marks, choose cool-down path.
4. **Subclass variants (same “tend the inner storm” pattern):**
   - Berserker → pure burn / reckless stoke
   - Totem / Wild Heart → animal spirit bargains & offerings
   - Ancestral Guardian → call / placate ancestor chorus
   - Zealot → vow brands & sacred pain ledger
5. **Refuse:** Rage as only a combat toggle with no between-desk; “dumb brute” lazy caricature as the whole identity.
6. **Soft-teaching:** Overstoke shows consequence on next fight preview; cool correctly unlocks clearer totem cues.
7. **Skip:** Pay time/gold for ritual service or accept default stoke (worse quality / harder recovery).

## Bard

1. **Stereotype:** Social physicist — words, songs, and scenes bend rooms; the party’s spotlight director.
2. **Field / domain:** Repertoire · audience heat · motifs · patronage.
3. **Loop texture:** Compose / rehearse a short motif (notes, lyrics, bit) → preview audience heat → bank for later scene. Hands: place beats, tag emotion, cut length.
4. **Subclass variants (same “shape a room with performance” pattern):**
   - Lore → cutting word / knowledge riff library
   - Valor / Swords → martial flourish choreography
   - Glamour → courtly glamour / dream-audience
   - Whispers → secret / fear motif bank
   - Creation → temporary prop / set-piece conjure
5. **Refuse:** Karaoke minigame as mandatory homework; endless dialogue trees as the only loop; stereotype as only “horny lute guy.”
6. **Soft-teaching:** Bad motif → readable audience drop; good motif tags which beat landed.
7. **Skip:** Use stock motif pack (gold/time) at quality floor; improvisation difficulty up if skipped practice.

## Cleric

1. **Stereotype:** Living radio to a god — rites, omens, and parish pressure; faith with paperwork and miracles.
2. **Field / domain:** Altar · liturgy · omen board · flock obligations.
3. **Loop texture:** Prepare rites on an altar grid (offerings, hours, domains) → read omen clarity → commit channel. Hands: slot prayers, weigh offerings, clear corruption.
4. **Subclass variants (same “tend the divine channel” pattern):**
   - Life → healing / flock vitality ledger
   - War → battle-bless / banner rites
   - Knowledge → scriptorium / omen catalog
   - Trickery → mask / misdirection rites
   - Nature → seasonal / rural parish rites
   - Death / Grave → boundary / funeral / undead pressure
5. **Refuse:** Pure menu of spells with no rite desk; cultural-lazy “generic priest”; mandatory daily mass homework.
6. **Soft-teaching:** Blurry omen → which offering mismatched; clear omen highlights the domain tag.
7. **Skip:** Tithe gold/time for temple proxy rite; quality/difficulty hit if you skip presence.

## Druid

1. **Stereotype:** Gardener of living systems — the land is a patient you tend, not scenery.
2. **Field / domain:** Grove / circle plot · seasons · symbiotic stock · wildshape affinity.
3. **Loop texture:** Tend a living plot (plant, prune, water, relocate species) → season tick → harvest boon / wildshape affinity. Hands: place flora/fauna tokens, set care orders, watch growth.
4. **Subclass variants (same “tend a living system” pattern):**
   - Circle of the Land → plants / biome plots
   - Circle of Spores → fungi / spore beds / rot cycle
   - Circle of the Moon → wildshape form care / apex forms
   - Circle of Stars → constellation garden / omen sky
   - Shepherd → beast spirits / flock
5. **Refuse:** Stardew wholesale; mandatory farming chore wall; “tree-hugger” lazy flatten.
6. **Soft-teaching:** Wilt shows neglected care axis; healthy plot unlocks clearer habitat reads in exploration.
7. **Skip:** Hire grove-keeper (gold/time) or let plot idle at quality/difficulty cost.

## Fighter

1. **Stereotype:** Professional of violence — drills, forms, kit, and the craft of not dying stupid.
2. **Field / domain:** Drill yard · maneuver cards · kit loadout · sparring ledger.
3. **Loop texture:** Run a short drill (stance → timing windows → commitment) → grade form → unlock/refresh maneuvers. Hands: time inputs on a form strip, swap kit pieces, mark spar notes.
4. **Subclass variants (same “drill the craft of fighting” pattern):**
   - Champion → pure form perfection / crit craft
   - Battle Master → maneuver recipe book
   - Eldritch Knight → weapon+cantrip weave drills
   - Arcane Archer → shot-arc practice / arrow recipes
   - Cavalier → mount/guard drill pairs
5. **Refuse:** Endless perfect-timing rhythm hell; “fighter has no fantasy” void; stealing a full fighting-game.
6. **Soft-teaching:** Missed window highlights which beat; clean drill tags the maneuver that unlocked.
7. **Skip:** Hire sparring partner / pay training gold for stock grade; quality floor.

## Monk

1. **Stereotype:** Body as instrument — breath, forms, and discipline that turns flesh into technique.
2. **Field / domain:** Forms · ki pool cadence · monastery vows · pressure points.
3. **Loop texture:** Practice a short form kata (breath sync + strike sequence) → ki cadence meter → bank focus. Hands: follow form ghost, match breath pulses, choose vow emphasis.
4. **Subclass variants (same “tune the body-instrument” pattern):**
   - Open Hand → pure form / redirect
   - Shadow → silence / smoke form variants
   - Four Elements → elemental kata overlays
   - Mercy → pressure-point heal/harm map
   - Astral Self → astral limb calibration
5. **Refuse:** QTEs as only identity; orientalism-as-product; mandatory meditation wall.
6. **Soft-teaching:** Desync shows which beat broke; clean kata brightens ki cues.
7. **Skip:** Pay time/focus incense for partial cadence; difficulty up if body is “cold.”

## Paladin

1. **Stereotype:** Walking oath — promises with teeth; aura and judgment you can feel in the room.
2. **Field / domain:** Oath ledger · tenets · aura tuning · sacred gear vows.
3. **Loop texture:** Review oath ledger (tenet stress, breaks, amends) → tune aura emphasis → seal or atone. Hands: weigh tenet tokens, assign amend quests, set aura posture.
4. **Subclass variants (same “live the oath ledger” pattern):**
   - Devotion → purity / honesty ledger
   - Ancients → light-vs-shadow / joy tenets
   - Vengeance → quarry / hunt oath
   - Conquest → dread / order aura
   - Redemption → spare / convert amend paths
5. **Refuse:** Lawful-stupid caricature as only path; mandatory sermon homework; oath as pure buff menu.
6. **Soft-teaching:** Tenet stress paints which vow cracked; amend path shows the repair action.
7. **Skip:** Pay penance gold/time via temple proxy; quality of aura down / difficulty of atonement up.

## Ranger

1. **Stereotype:** Edge-walker who reads land and quarry — maps, marks, and a bond that hunts with you.
2. **Field / domain:** Hunt board · terrain marks · companion / bond · route craft.
3. **Loop texture:** Mark quarry/terrain on a hunt board → set route & traps → tend companion/bond. Hands: place marks, draw route, feed/train bond, set ambush tags.
4. **Subclass variants (same “read land & bond to hunt” pattern):**
   - Hunter → quarry specialization board
   - Beast Master → companion care/loadout (continuous)
   - Gloom Stalker → underdark / first-strike marks
   - Horizon Walker → portal / planar trail marks
   - Fey Wanderer → fey bargain / mist marks
5. **Refuse:** Compulsory pet micromanagement; “ Aragorn clone” as only fantasy; full survival-sim homework.
6. **Soft-teaching:** Bad mark → missed quarry preview; good mark highlights habitat tells in exploration.
7. **Skip:** Buy guides/bait (gold) or idle companion (quality/time cost); never hard-gate travel.

## Rogue

1. **Stereotype:** Problem as a lock — angles, timing, leverage, and the clean getaway.
2. **Field / domain:** Heist board · tools · marks · escape routes · cover identity.
3. **Loop texture:** Plan a short score (entry → leverage → exit) on a board → practice timing → bank tools/marks. Hands: place entry points, set distraction tags, test lockpick timing strip.
4. **Subclass variants (same “solve via angle & timing” pattern):**
   - Thief → climb / tool / second-story
   - Assassin → disguise / strike setup
   - Arcane Trickster → mage-hand / spell-mark tricks
   - Mastermind → social leverage / crew board
   - Scout → wilderness angle / mobile marks
5. **Refuse:** Mandatory stealth sudoku; “edgy orphan” lazy flatten; full Hitman level editor.
6. **Soft-teaching:** Failed practice shows which beat blew (noise, time, angle); success tags the tool that mattered.
7. **Skip:** Bribe / buy info / hire lookout (gold/time); quality of plan down.

## Sorcerer

1. **Stereotype:** Magic in the blood — raw current you shape, not homework you memorize.
2. **Field / domain:** Bloodline current · metamagic dials · surge risk · body tells.
3. **Loop texture:** Shape a short current (aim, intensity, metamagic dials) on a living field → ride surge risk → bank a shaped effect. Hands: pull field nodes, twist metamagic rings, hold surge.
4. **Subclass variants (same “shape innate current” pattern):**
   - Draconic → elemental breath/current tint
   - Wild Magic → chaos surge table you learn to surf
   - Shadow · Divine Soul · Storm · Clockwork — each retints the same dials (void, grace, weather, order)
5. **Refuse:** Wizard spellbook clone; “random screw you” as only Wild identity; anime-beam spam as the whole loop.
6. **Soft-teaching:** Surge blowback highlights which dial overfed; clean shape tags the metamagic that landed.
7. **Skip:** Rest-stabilize (time) or pay focus reagents (gold) for safer default shape; quality/difficulty trade.

## Warlock

1. **Stereotype:** Dealmaker — power on a contract; patronage with invoices and nightmares.
2. **Field / domain:** Pact desk · patron favors · invocation slots · debt clock.
3. **Loop texture:** Negotiate / fulfill a short pact task on the patron desk → spend/gain favor → lock invocation. Hands: accept terms, deliver tokens, rearrange invocation sockets.
4. **Subclass variants (same “work the patron contract” pattern):**
   - Fiend → soul-ledger / temptation favors
   - Archfey → whim / dream bargains
   - Great Old One → san/insight / wrong geometry tasks
   - Hexblade → weapon-as-patron / oath-edge
   - Celestial → mercy invoices / light debt
5. **Refuse:** Pure edgelord cosplay; mandatory creepy homework; patron as only a spell list skin.
6. **Soft-teaching:** Broken term flashes which clause; fulfilled favor unlocks clearer invocation preview.
7. **Skip:** Pay extra favor/gold/time to autocomply via lesser offering; debt difficulty up.

## Wizard

1. **Stereotype:** Scholar of the weave — books, labs, and careful theft of the universe’s rules.
2. **Field / domain:** Spellbook · lab bench · copy/transcription · theory board (fields to balance).
3. **Loop texture:** Lab / book desk: align field nodes (soft-teaching “electromagnetic” balance metaphor ok) → transcribe/copy spell → stress-test. Hands: balance nodes, ink glyphs, slot reagents, confirm copy.
4. **Subclass variants (same “study & rewrite the weave” pattern):**
   - Evocation → raw energy field shapes
   - Abjuration → ward lattices
   - Divination → omen / portents board
   - Necromancy → boundary / thrall notes (careful stereotype watch)
   - Illusion → sensory falsework
   - Bladesinging → form+spell weave (martial-scholar)
5. **Refuse:** Homework spreadsheet as the fun; copying Sorcerer’s innate current loop; stealing a specific puzzle game wholesale.
6. **Soft-teaching:** Unbalanced field shows which node drifts; clean balance unlocks the spell’s readable “why.”
7. **Skip:** Pay scribe/gold/time for stock copy at quality floor; harder cast difficulty if untested.
