# Combat play-surface texture

**Role:** Player-facing texture for the **shared combat play surface** (`ux_combat_play_surface`). Pattern language only. **Not locked.** Pin gate remains **open**. Not applied seasoning. Not share-ready. No new PIN-INDEX titles. No game titles proposed as `conceptual_pin`.

**Grounded in:** [[combat-altitude-map-siege-raid]] · [[turn-gated-movement-circle]] · series pin `ux_combat_play_surface`. Cards this pass: [[combat-threat-readability]] · [[combat-flank-blind-spot-arc]] · [[combat-enter-exit-residue]].

**Not this pass:** altitude desks (map / siege / raid already exist). Class-expression desks (inspiration, stun, smite economy, etc.) stay on [[CLASS-EXPRESSION-BOARD]]. No second parallel combat desk.

---

## Job

The table **orchestrates** the fight. The surface supports **precision**. Above-table player talk is the primary channel. The surface does not replace the conversation.

Combat is a **called window** the whole table enters and exits. System assists. DM owns the call.

---

## Locked brief (2026-08-11)

### 1. Threat readability — common humanoid default

Weapon posture is a **continuous, low-chrome cue visible before combat starts**. Primary channel for the common case, not a complete taxonomy.

| Read | Signal |
|------|--------|
| Melee (“swingy”) | Sword / weapon in hands **or** on back |
| Ranged / other (“shooty”) | Free hands **or** obvious ranged posture |

Edge cases (monks, pure casters, monsters, dual-wield, hidden weapons, …) stay open to **Nature / Insight / Investigation** or **DM feed**. Learn-by-doing is first-class. Pre-fight information beyond this default stays **optional**.

### 2. Nature threats — outline assist

Nature check (or equivalent) **may** surface simple outline language:

| Color | Meaning |
|-------|---------|
| Green | Friendly / indifferent |
| Yellow | Can be agitated into hostility |
| Red | Actively predatory |

Low-chrome assist only. Failure / skip = no outline, not blindness.

### 3. Flank / blind-spot

- **Arc:** 180° measured from the enemy’s **back**.
- **Gradient:** closer to the center of the back = higher bonus.
- **Illustrative scale (not product law):** tight rear cone ≈ +1; wider rear arc up to 90° ≈ +3. Exact numbers stay **rules-side**.
- **Visual assist:** short cone/arc overlay in the **same visual family** as the existing turn-gated movement circle, reaching **~5 ft** from the enemy’s back.
- **Who / when:** acting player only; combat-surface only. Does **not** grid the whole world.

### 4. Class contribution

Already owned by class-expression desks. Shared surface only needs to remain **readable** when those desks are present. No second parallel combat desk.

### 5. Orchestration

Above-table player talk is primary. Surface supports precision; it does not replace the conversation.

### 6. Enter / exit + residue

| Beat | Owner | Texture |
|------|--------|---------|
| Open | DM calls initiative (or equivalent) | System assists (chrome, audio, movement circle, flank overlay) |
| Close | DM designates last turn / official end | System assists only |
| Residue into quiet-between | System fade | The breath when they realize they are still alive: red border fades; heartbeat slows and softens; heavy breathing fades; combat chrome recedes **without a hard cut**. Fiction stays continuous. |

Authored ends (fight, disengage/flee, parley, stakes, surrender, escape-with-cost, …) stay on the **existing series contract**. Residue is sensory texture into quiet-between — not a new end menu.

## Explicit refuse list

Do **not**:

1. Invent a complete threat-taxonomy HUD (nameplates, aggro meters, always-on health as the readability channel).
2. Make pre-fight inspect / dossier a **gate**. Extra pre-fight info stays optional.
3. Treat weapon posture as sufficient for monks, pure casters, monsters, dual-wield, etc.
4. Make Nature outline a second combat desk or a hard gate.
5. Grid the whole world with flank cones / movement chrome.
6. Show flank overlay always-on for all actors / all seats / outside the combat window.
7. Lock illustrative +1 / +3 as product law (numbers stay rules-side).
8. Replace above-table orchestration with overlays.
9. Open a second parallel combat desk beside class-expression.
10. Auto-start or auto-end combat without the DM call.
11. Hard-cut exit / loading sting as the only leave; always-on fight chrome that never recedes.
12. Treat residue as a new authored end or mandatory after-action report.
13. Propose game titles as `conceptual_pin` from this pass.
14. Claim share-ready or close the pin / seasoning gate from this pass.
