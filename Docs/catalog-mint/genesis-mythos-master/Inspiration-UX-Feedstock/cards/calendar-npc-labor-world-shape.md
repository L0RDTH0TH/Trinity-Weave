# Players design · NPCs labor · calendar wait

## Locked split

| Layer | Pattern job | Exemplars |
|-------|-------------|-----------|
| Intent surface | What the base *should* become (click-add / light blueprint) | Townscaper (+ Foundation-class designate) |
| Realization | Who builds it and when | NPC/minion/settler labor **on a calendar** |
| Refuse | Player in the place-build loop | Rust / ARK / Minecraft default |

| Texture | Job |

| **B** | Specialist crew / blueprint — keeps, workshops, infrastructure |
| **C** | Goal / bounty → autonomous agents — background mode **and** sprinkled inside A/B |
