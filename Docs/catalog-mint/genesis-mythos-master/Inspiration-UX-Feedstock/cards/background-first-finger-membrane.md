# Background — first finger / membrane

**Job:** the character’s first already-recognized **social/professional** membrane / finger into the world.

## Pattern

| Beat | Texture |
|------|---------|
| **Push** | Something in the origin pushed the character onto the adventurer path. Background is where that origin pressure is expressed. |
| **Feedback** | Both **mechanical** (domain knowledge, appraisal, warmer institutional doors) and **meaningful** (living contacts, villagers hide a Folk Hero, former squad-mate appears, etc.). |
| **Scope** | Social / professional only. |

## Power-band decay (soft guidance)

Keyed to observable power / reach more than exact level numbers:

| Band | Feel |
|------|------|
| **C3** (lv1) | Mostly latent |
| Near top of low band (**≈C1**) | Related factions begin reacting |
| Through early **B** | Reaction window still live |
| **B1–B2** into early **A** | Fully absorbed / moot |

## Session 0 gate

Named critical-node or specific faction linkages require **DM approval** at Session 0.

## Absorption (intended end-state)

Residue is swallowed into **reputation weather**, **faction fingers**, and **knowledge-flow** systems. Does **not** remain a permanent second identity layer or unique ability.

## Completeness

Classic PHB skill + tool + feature skeleton is kept as **content form** but is **insufficient alone**. The lasting world impression + decay / absorption **completes** the pattern.

## Refuse (required)

- Permanent unique ability / second class desk
- Forced personal campaign spine
- Sheet-only existence
- Ecological / planar / monster-raised origins on this surface
- Strong residual pressure from level 1
