# Tool use as presence

**Job:** using a tool is an event in the place, not a silent number.

## Pattern

The attempt leaves **residue** the table can see or feel:

- noise
- time
- traces
- altered object

Success and failure both leave something. The number is not the whole outcome.

Active tool use may also surface a low-chrome assist (same family as `skill-active-passive-assist`). Not required to act.

## Soft teaching

Tools and their readability assists can be learned or revealed through play. No mandatory training desk for every case.

## Refuse (required)

- Pass/fail number with no residue
- Mandatory training montage for every proficiency
- Class desk required for tools to exist
- Inspect-to-act gate
