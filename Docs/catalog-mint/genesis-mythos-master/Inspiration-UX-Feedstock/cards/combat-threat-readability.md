# Combat threat readability

Continuous, low-chrome cue **before** combat starts. Primary channel for the **common humanoid default**, not a complete taxonomy.

## Common humanoid default — weapon posture

| Read | Signal |
|------|--------|
| Melee threat (“swingy”) | Sword / weapon in hands **or** on back |
| Ranged / other (“shooty”) | Free hands **or** obvious ranged posture |

Visible in the world. No extra chrome required. Learn-by-doing is first-class.

## Edge cases (open)

Monks, pure casters, monsters, dual-wield, hidden weapons, etc. remain open to **Nature / Insight / Investigation** or **DM feed**. Do not invent a second taxonomy HUD to close them.

## Nature threats — outline assist

Nature check (or equivalent) **may** surface simple outline language:

| Color | Meaning |
|-------|---------|
| Green | Friendly / indifferent |
| Yellow | Can be agitated into hostility |
| Red | Actively predatory |

Low-chrome assist only. Optional. Failure / skip = no outline, not blindness.

## Orchestration

Above-table player talk is the primary channel. This surface supports precision; it does not replace the conversation.

## Refuse (required)

- Complete threat taxonomy HUD
- Mandatory pre-fight inspect gate
- Always-on MMO chrome as the readability channel
- Pretending posture covers monks / casters / monsters
- Nature outline as a desk or gate
