# Liked snippets (operator)

Pattern extraction only. Pillars: Exploration · Roleplay (incl. factions/guilds/NPC sheets) · Combat. See [[PILLARS-AND-LENS]].

## Product lens

Multiplayer living-world fantasy + real DM/player agency in 3D. When players imagine system A / action X through game G → pattern → our systems → refuse.

## Shared-world / digital D&D

- **BG3:** Best digital D&D feel (roleplay + combat). **Refuse:** single-player crafted story spine — we want multiplayer open-world chaos.
- **Destiny:** Shared-world multiplayer drop-in feel. **Refuse:** 3-player fireteam limit and real-time shooter combat (we’re table-scale, turn-based).

## Open-world cluster

Skyrim, Oblivion, KCD/KCD2, Hogwarts, RDR, Fable — mine together for aliveness/consequence/exploration.

- **Skyrim:** Living world; FP “share with brothers.” Mod ecosystem = community marking weak exploration/survival and augmenting it.
- **Fable:** Relationship-shaped economy/social (prices, marriage) vs thin item romance gates.
- **KCD/KCD2:** Low-fantasy tone / power bar.
- **Hogwarts:** Seasonal rewrite of the same place.
- **RDR:** Mount / landscape movement.
- **Oblivion:** Same open-world cluster — thicken in dialogue.

## Mods (weak-spot research)

Players wanted better exploration/survival in Skyrim → Campfire (+ Frostfall, etc.) — not built in a vacuum. Research **what was weak** and **how the community augmented it**. Placement glow / clip-valid feedback in those tools can rhyme with DM Forge placement (same outline; DM is free-cam).

## Tools / lenses

- **Halo Forge:** DM place glow valid/invalid, menus, hide; live grid correspondence; review playback.
- **Cities (implicit):** Situational overlays/lenses on a living place — not “combat circle = Cities.”
- **Combat circle:** Operator invent for combat desk.
- **TaleSpire:** DM tooling re-expressed for FP players.

## DM resource layer

Stellaris / Dwarf Fortress / **Civilization** / Anno — background resource/politics so the world feels alive; **DM overrides first-class and intentional**. Sliding investment (~3–5×), not full 4X homework.
