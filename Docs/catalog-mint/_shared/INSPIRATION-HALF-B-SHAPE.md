## Error mode this law closes

Operator expected Inspiration-UX-Feedstock **flavor/shape** to affect Half-B output. Demo lacked that flavor → clue that inspirations were **absent from relevance** (not wired as source-of-shape for factory output). Demo-narrow provisional catalogs do **not** fix this. Generalize: inspiration → output shape is Half-B law for **all** properly shaped artifacts.

## Half-B must do (every properly shaped artifact)

Before claiming staging progress on a weld (generate **or** update):

1. **Resolve shape sources** for the target artifact: Inspiration INDEX/cards mapped to the row (or L5 / ASSUMPTION-LOG seasoning cites). Visual lane also loads [[Visual-Factory-Direction-Stylized-Low-Poly]] when the artifact is visual.
2. **Name the flavor/shape** in the hand-off / receipt: which move-pin(s) or visual bar the output is shaped by.
3. **Refuse clones** — pattern extract only; never game-title Conceptual pins; honor `refuse_to_copy` / `does_not_mandate`.
4. **Prove relevance** — output must show the named flavor (UX feel, interaction grammar, or visual language). Stock/FPS/F5 prove *how*, not *shape*.

Applies to **all** factory artifacts with a catalog/L5/inspiration path — not only horizon demo rows.

| Code | When |
|------|------|
| **`inspiration_shape_miss`** | Inspiration feedstock / seasoning / visual bar exists for the artifact’s row or lane, but Half-B output lacks that flavor/shape (generic chrome, demo-narrow menus, or stock-only proof with no shape cite). |

- Hand-off omits shape sources though feedstock maps exist for the row.

Severity: **block** for Success / `ask_success` / `factory_greenlit` claims. Staging checkpoints may continue only with honest `claim_class: staging` and an explicit `inspiration_shape_miss` debt note — never silent.
