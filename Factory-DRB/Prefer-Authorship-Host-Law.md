# Prefer Authorship Host Law (constitution-grade)

**Binding** for Prefer / Half-B worldgen and Terrain3D-feed slices. Not advisory brief text. Not a debt sticky.

## Thesis (failure patterns this law closes)

1. **Proxy metrics ≠ product truth** — budgets, file existence, shell seats, stub drops, SP paperwork cannot alone pass Prefer.
2. **Law must bind agents** — Prefer/authorship experiential contracts are fail-closed harness seats, not soft prompts.
3. **Stale topology must not run** — unowned armed paths / identity drift / shell-era checklist under worldgen Prefer → hard-fail before first lane agent.
4. **Synthetic completion is cheaper than production** — bootstrap stubs, duplicate continues, waives, synthetic attestation must not close tickets.
5. **Durable negative examples** — F5 corrections survive every Prefer, not one brief.
6. **Explicit without implicit** — lanes meet countable Success while ignoring locked inspirations (YT / feedstock / topology). Entry seat must **bind** implicits into `done_when` + refuse codes **before** `IMPLEMENT_SLICE`, and re-check after.
7. **Intent validates gates** *(binding — [[prefer_intent_validates_gates_r1]])* — Prefer / decision-matrix / feedstock **guide through intent**; mechanical Prefer green does **not** prove intent; gates may change when intent requires. Failure family: `proxy_substitution` (intellectual laziness via proxy stand-ins).

- `prefer_authorship_pass` loads the bind itself; on `topology_rewrite` it runs a **LIVE** scan of craft-host / occupancy paths named by the armed packet (historically `Systems/DualGridCraftHost.cs` + `Core/WorldGen/Hex19OccupancyLattice.cs` — those files lived under the **scrapped** mini-game exhibit; re-bind paths when a new exhibit exists) and emits **structured evidence** (edge / face-cell / point signals, files scanned) into the seat receipt. Comments and string literals are stripped — a doc comment claiming edges is not evidence.
- Edges **and** faces/cells are both required. Points-only → `points_as_grid` + `count_equals_topology` + `explicit_met_implicit_miss`; all three are in `PRODUCT_PREFER_DO_NOT_WAIVE` (non-waivable, injected by lane runner and PQ staging).
- `validate_producer_receipt` **hard-fails** when `implicit_bind_path` is absent or the artifact fails `validate_bind_artifact`. A bind older than the armed packet's `law_amended_at` is stale (`implicit_bind_stale_vs_armed_law`) and is force-recomposed on re-weld.
- PQ staging resolves the sibling `{slice_id}.armed.yaml` and injects `armed_packet_path` / `half_b_brief_path` / `ask_id` / `do_not_waive`. Staging is **never** refused on armed-packet state: there is no `operator_go` / `do_not_auto_dispatch` word-gate (the 2026-10-03 revert removed it — GO is an operator chat kickoff, and latching it in YAML only blocked the factory). A composed slice that differs from the project's armed slice yields an advisory `armed_slice_divergence` note on the staged result, not a refusal. Enforcement lives in the topology seat, post-lane, on LIVE code.
- `locks.step1_authorship` (or `locks.step1_occupancy`) **dict** is the required shape; a bare `step1_authorship: true` still passes but warns `step1_authorship_bool_underspecified`.

**`topology_rewrite` is law-derived (2026-10-03).** The axis is armed from the **resolved armed packet** — caller-supplied, else `armed_packet_path`, else the project's `factory-project.yaml → armed_packet` pointer (`resolve_armed_for_bind`). Triggers, recorded in `topology_rewrite_sources`:

| Trigger | Source tag |
|---------|-----------|
| `locks.step1_authorship.refuse` / `locks.step1_occupancy.refuse` names `points_as_grid` / `count_equals_topology` / `explicit_met_implicit_miss` / `infinite_rect_as_hex19` | `armed_lock_refuse:*` |
| `structural_success` / `done_when` / `hard_prefer_gaps` (or the lock's `structural_success` / `law` / `replace_live_assumption`) names a lattice / topology, or spells out vertices + edges + faces/cells | `armed_structural_topology:*` |
| `prefer_authorship` / `step1_authorship` armed **and** a topology law or cite is locked | `armed_prefer_authorship_with_topology_law` |
| Composed refuse list already carries a topology code | `composed_refuse:*` |
| Ask / slice-id prose matches the points-grid regex — **secondary only** | `ask_prose` · `slice_id_prose` |

Fail-closed consequences — a reworded ask cannot make the seat go quiet:

- A bind that claims `topology_rewrite: false` while armed law arms the axis → `implicit_bind_topology_rewrite_disarmed_vs_armed_law:*` at preflight.
- A Prefer-applicable slice whose composed bind claims `topology_rewrite: false` → `topology_rewrite_disarmed_on_prefer_slice:<slice_id>` from `prefer_authorship_pass` itself.
- The LIVE topology scan runs on the **effective** axis (bind flag **or** armed law), so a disarmed bind still gets scanned and still collects `points_as_grid` / `count_equals_topology` / `explicit_met_implicit_miss`.
