# Prefer audit — proxy-substitution pattern

## Verdict

**Failure family** (not a dual-only glitch). Agents treat Prefer gate green / countable proxies as *proof of intent*. Wrong direction.

Doctrine correction (operator):

> **Intent validates the gate’s shape** — gates serve intent; Prefer / decision matrix / feedstock must guide the agent through intent. Mechanical Prefer green does **not** prove intent; intent may revise refuse/gates.

## Pattern

| Stage | What agents did | What intent required |
|-------|-----------------|----------------------|
| Topology | “N points present” | Lattice graph (vertices + edges + faces) |
| Dual visual | Stretch / AABB symbols | Discrete silhouette family |
| Dual neighborhood | Stable ≤4 ownership | Ownership of the **dual** object |
| Dual lattice (exemplar) | Cyan 2×2 primary faces | Half-step dual lattice cells |

Common mechanism: **proxy substitution** — a cheaper measurable stand-in (count, stretch, stable-≤4, scanner symbol) sold as Success for a different object class.
