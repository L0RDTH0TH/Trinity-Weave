# Godot MCP plugin (Asset Library #4767)

Manual install — [Godot AI Assistant tools MCP](https://godotengine.org/asset-library/asset/4767) (tomyud v0.5.0).

Source: https://github.com/tomyud1/godot-mcp (`addons/godot_mcp/`)

## Enable in editor

1. Open this project in Godot 4.6.3 .NET
2. **Project → Project Settings → Plugins**
3. Enable **Godot MCP**
4. Top-right should show **MCP Connected** when Cursor runs `npx godot-mcp-server`

## Cursor MCP

`~/.cursor/mcp.json` → `npx -y godot-mcp-server` (editor must be open with this project).
