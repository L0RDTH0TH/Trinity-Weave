# Felt moment (pattern language)

The game begins by **taking control away**: cage, experiment, parasite, captivity. First hours teach the feel of violated agency, then return locomotion and choice piece by piece. Exploration is escape authorship. Lore arrives as residue in the prison (notes, victims, beautiful rooms that do not belong). Personal stakes precede world-saving rhetoric.

## Spatial / temporal / control

Claustrophobic start; camera/control deliberately limited then restored. Soft framing from the captor’s presence. Player authorship is “how I get out,” not “which quest board.”
