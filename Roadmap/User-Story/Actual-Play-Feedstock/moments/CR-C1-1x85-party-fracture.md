# Felt moment (pattern language)

After trauma and perceived neglect, a core member **leaves the party**. Not death — exit. The remaining table sits in the quiet: blame, love, logistics, empty chair. Models social-contract rupture better than any wipe. Later return (if any) is a separate pattern; this card is the rupture itself — authorship of absence.

## Spatial / temporal / control

Domestic / camp spaces. Soft framing from silence. No encounter HUD. Control is whether anyone tries to stop the exit and how the fiction marks the hole.
