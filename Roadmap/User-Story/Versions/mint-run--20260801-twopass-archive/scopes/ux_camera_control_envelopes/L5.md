# L5 — `ux_camera_control_envelopes`

## What it is

Baseline player FP and a set of explicit temporary envelopes that change perspective and/or control then hard-restore. Overrides (scry/divination, dominate, liminal/unconscious, planar/gate, absent-proxy, etc.) always return to baseline FP or the declared prior state. DM rail is first-class in the same parent: WorldCam is the DM default; MapCam, Sensorium Attach, and DM pilot are explicit departures with hard restore. Players never use WorldCam/MapCam. Every enter declares controller, presentation, duration, and return target.

## Seat defaults (locked)

- **Player default:** first-person embodiment.
- **DM default:** WorldCam (free-flight). MapCam, Sensorium Attach, and DM pilot are explicit envelope departures with hard restore.
- Players never receive WorldCam/MapCam as exploration seats.

## Liminal / unconscious

First-class named envelope with enter/exit and hard restore (thin PoC OK). Not deferred solely to coverage.

## Dominate pilot/victim

PoC depth flexible: thin inclusion or coverage deepen — both acceptable under this contract.

## Full vision

- Named envelopes for both seats share enter criteria, presentation, duration, hard restore
- Body-change effects stay FP from the new body
- DM tools feel like mastery seats, not debug
- Coverage deepens override chrome, interpolation, rich victim/liminal presentation

## Early / PoC cut

Baseline FP + at least one player override with hard restore; liminal/unconscious with hard restore (thin OK); DM WorldCam (default) and MapCam first-class with enter/exit; dominate optional thin; thin transition graph. Defer rich Sensorium suites and full pilot handoff persistence ledger.

## Hard dependencies

Collaborative table agency and live play. Not blocked on full combat-surface depth or living-world continuity.

## Out of scope

Free third-person orbit as player default; DM tools as debug-only; soft residual after exit; permanent never-return camera modes; full spell metadata; shell.

## Alternatives not banned

- Heavy vs light transition interpolation (comfort) as long as final state is hard-restored
- Sparse vs frequent override use
- DM who rarely leaves WorldCam vs frequent MapCam / Sensorium / pilot use
- Strict rules-only overrides vs session-policy additions (absent proxy, custom visions)
- Minimal vs rich liminal/unconscious or dominate-victim presentation
- Thin vs fuller dominate pilot/victim in early builds

## does_not_mandate

- players get free third-person orbit as default
- DM tools exist only as debug infrastructure
- envelope exits leave soft residual control or wrong perspective
- camera modes can become permanent without a restore path
- players may use WorldCam or MapCam as free exploration seats
