# L5 — `ux_late_game`

## What it is

Late-game is the high power band: survivors are world-shapers. It covers build-up to close and the close itself. DM triggers campaign end through a story crescendo visible in play; players map retirement/future plans; those characters persist as powerful DM-controlled NPCs in the living world. Default continuation is a new campaign in the same world; other topologies remain via world/campaign parents. Not one mandatory finale skin; not session prep.

## Catalog placement note

**Default happy path after close:** new campaign in the **same world**. Multi-world / multi-campaign-per-world remain capabilities on world/campaign parents — not banned, not the named default here.

## Decision (operator)

Power band on stage rows (early / mid / **late**). No separate progression series parent. Id renamed from `ux_end_game` so the noun matches a multi-session high band, not only the final beat.

## Full vision

- Late band as campaign/cast state
- Crescendo → DM end trigger → retirement/future-plan capture → NPC persistence in world sim
- Same-world next campaign as default; other topologies via existing parents
- Prep may stage late situations; band + close/persist own the contract

## Early / PoC cut

Late-band flag, DM end trigger, thin retirement-plan capture, character becomes DM NPC flag on the world. Defer full continent-scale sim and rich legacy chrome.

## Hard dependencies

World persistence and living-world path; DM control of NPCs after handoff. Natural after early/mid bands.

## Out of scope

Session prep as the close system; forcing one finale exemplar; deleting player legacies by default; replacing world/campaign parents; shell.

## Alternatives not banned

- Abrupt DM end vs long staged crescendo
- Heavy retirement planning vs light future-notes
- Same-world next campaign immediately vs gap time in world sim only
- Multi-world / multi-campaign setups via existing parents

## does_not_mandate

- the only correct ending is institutional seizure
- end game must erase player legacies
- progression requires a separate series parent from stage bands
- session prep replaces the late power-band / close contract
- post-close must start in a different world by default
- late play is only the final session, not a high power band
