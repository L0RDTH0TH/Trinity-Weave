# L5 — `ux_quiet_between_pillars`

## What it is

In-adventure quiet is the product surface for time between pillar bursts — road, camp, linger, and other low-intensity presence — so fiction stays continuous while the table is not in a forced combat, social set-piece, or explore objective. Quiet is largely the system waiting for players and DM to move the story forward. Between-adventures weeks/months sit with living-world continuity, not this parent.

## Boundary

**This row:** in-adventure quiet (road/camp/linger between pillars).  
**Not this row:** between-adventures weeks/months → `ux_living_world_continuity` (when walked).

## Full vision

- Playable low-intensity states inside an active adventure
- Clean enter/leave relative to combat, social, explore without a mandatory menu break
- Power band still gates who and what shows up in the quiet
- Prep may stage quiet stretches; this row owns that quiet is designed surface
- Calendar-scale downtime owned elsewhere

## Early / PoC cut

One in-adventure quiet path (road *or* camp linger) that stays in-world and FP-capable; system idle-for-table-advance is real; rest can hook without defining the surface. Defer multi-site downtime graph and between-adventures projects.

## Hard dependencies

Live play path; thin world/campaign context. Not blocked on full living-world off-screen sim.

## Out of scope

Between-adventures calendar downtime; combat/social resolution systems; quiet only as long-rest pump; mandating BG3 campsite companion UI; shell.

## Alternatives not banned

- Camp-centric vs road-centric vs both inside the adventure
- Quiet as distinct mode vs low-intensity state in the same world view
- Rest embedded in quiet vs separate rest verb usable during quiet
- Sparse linger vs frequent light authored beats on the road

## does_not_mandate

- downtime equals BG3 campsite companion UI
- quiet is only a long-rest resource refill
- quiet is a loading state between pillars
- this row owns between-adventures weeks/months calendar downtime
- system must force the next combat social or explore beat during quiet
