## Job

Outside the Artificer subclass desk, magic-item creation is primarily an **NPC / world process** that players access by **commission**. A Wizard or other character *might* attempt personal work; the ordinary path is outsourcing. **No new shared player crafting desk** is opened.

---

## Locked brief (2026-08-11)

| Job | Pattern |
|-----|---------|
| **Commission as RP interaction** | Player talks to the merchant, smith, temple workshop, independent magic-material dealer, or faction-affiliated store. That conversation is the surface. |
| **Formula evaluated against current state** | Item base + magical reagents (what makes it magic) + time spent inscribing / binding the magical logic. Evaluated from what the local economy and networks actually have right now. |
| **Economic questions the surface answers** | Is the base item in local stock? Cheaper or faster to import vs commission from the local smith? Did the player already make the base themselves with tools? Scarcity, caravan status, and local production flex the answer. |
| **Realism bar** | Background economy (caravans, production, scarcity) runs whether the party is present or not. Presence only renders the state (empty shelf, late shipment, inflated reagent price). Avoid classic video-game unrealistic static economies. Do **not** sim mundane paperwork ink; **do** care about magical reagents and the binding work. |
| **Faction interlacing** | Independent merchant vs faction-affiliated store. Relationship and membership change price, access, priority, and what is offered. Same institutional-weather rules (fingers + ripples, reputation weather, goal-pressure residue). |
| **Residue** | Finished or failed work carries provenance into Inventory. Claim pressure follows existing network-routed rules. |
| **Boundary** | Artificer subclass desk owns the specialist personal / field-test loop. Everyone else uses the commission conversation. Skip / murderhobo still apply to any optional packaging; the world and NPCs keep operating. Provenance, claim, and knowledge ladder already cover the object once it exists. |
