# Voice changers as table / IC signaling

Light table surface. Density stays low.

## NPC voice (DM)

Set of waveforms that can be **freely manipulated** on the fly.

| Case | Pattern |
|------|---------|
| Quick one-off | Improvise or use default. No setup required. |
| Recurring character | Tune the changer to the desired sound and **save it to that NPC**. When the DM speaks for that NPC, the tuned voice is applied. |

## Player character voice

Players set their character’s voice the same way. Intentional **“speak in character”** button (or equivalent signal) activates it. **Optional, never mandatory.**

## Defaults and speed

Default voice always available. No requirement to configure anything for a throwaway line. Manipulation surface must stay **fast enough for live table use**.

## Possession / World-cam

When the DM possesses an NPC in World-cam, the saved voice profile for that actor should ideally **auto-apply** or be **one click away**. Consistent with skeleton-key posture.

## Boundary

DM remains the author of NPC speech. System supplies the voice transform; it does **not** invent dialogue or replace the DM. Lives under collaborative table agency and roleplay. Not a product voice-acting mandate. Not a class desk. Not a combat pin.

## Refuse (required)

- Preset-picker as the only path
- System-authored NPC dialogue replacing the DM
- Mandatory player voice changers
- Voice tooling as a combat or rules pin
