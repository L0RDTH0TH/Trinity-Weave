# Travel modality — content through existing membranes

**Job:** make travel modalities **explicit as content** through membranes that already exist — not a new pillar or desk.

## Hard refuse (already locked)

**No mundane fast travel** as default.

## Modalities (illustrative)

Mounts (land / air), airships, carts, wagons, polymorph travel forms, teleportation and similar — whatever the world and power band can actually support.

## Expression rule

Each modality is an expression of:

1. **Power band** (what the party / world can sustain)
2. **Local availability** (structures, factions, ecology, stock)
3. **Seed-region / quiet-between pressure** (distance, scarcity, danger)
