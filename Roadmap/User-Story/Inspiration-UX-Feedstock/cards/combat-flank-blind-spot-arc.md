# Combat flank / blind-spot arc

**Job:** show the acting player whether they currently have the flank bonus — not a global tactics HUD.

## Pattern

- **Arc:** 180° measured from the enemy’s **back**.
- **Gradient:** closer to the center of the back = higher bonus.
- **Illustrative scale (not product law):** tight rear cone ≈ +1; wider rear arc up to 90° ≈ +3. Exact numbers stay rules-side.
- **Visual assist:** short cone/arc overlay in the **same visual family** as the existing turn-gated movement circle, reaching ~5 ft from the enemy’s back.
- **Who sees it:** the **acting player only**.
- **When:** combat-surface only. Does not grid the whole world.
- **Scope (carry-forward — lock when Combat surface closes):** 180° is the **humanoid default**, not a universal monster law. Good default for bipedal humanoid-shaped threats; other anatomies / senses get their own readability language (or none) later. Not locked this pass.

## Orchestration

Above-table player talk remains the primary channel. The overlay supports precision; it does not replace the conversation. Class-expression desks (inspiration, stun, smite economy, etc.) stay on those desks — this is shared-surface readability only.

## Refuse (required)

- World-as-grid
- Always-on cones for everyone
- Overlay outside the combat window
- Treating illustrative numbers as locked math
- Overlay replacing table talk
