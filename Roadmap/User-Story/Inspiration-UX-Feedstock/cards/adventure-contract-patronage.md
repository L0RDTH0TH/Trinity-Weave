# Adventure contract / patronage — job as content through membrane

**Job:** name the **hook → play** path so jobs stay content through existing membranes — thin RP + system tag, not a quest desk.

## Named path

Hook and patronage ride:

1. Faction fingers / institutional weather
2. Session-prep patterned branches
3. Commission / local finger conversation (when the “job” is making or sourcing)
4. Claim / treasure / favor heat
5. Optional join to apex pressure when the contract is a BBEG finger

## Texture

Mostly **RP + system tag**. The living world remembers who asked, what was promised, and what residue failure or success leaves.
