# Quiet surface boundaries

**Job:** keep in-adventure quiet as continuous fiction — and keep it from eating neighboring surfaces.

## Continuous fiction

Same world, bodies, and relationships persist. Tone does not reset. Quiet is intentional product, not dead air or a loading state.

## Boundary table

| Neighbor | Relation |
|----------|----------|
| Combat exit residue | **Already locked.** Hands into quiet: red border fades; heartbeat slows and softens; heavy breathing fades; combat chrome recedes without a hard cut. DM still owns the official end call. |
| Institutional weather | Continues inside the loop (ripples on the road / in camp). Not suspended. |
| Class-expression desks | May still be opened inside quiet. Quiet does not require a desk for texture. |
| Living-world continuity | Owns **between-adventures weeks/months** calendar downtime. Quiet does **not**. |

## Refuse (required)

- Quiet owns weeks/months downtime
- Hard-cut mode switches with no residue
- Loading state between pillars
- Tone reset / companion-camp UI as continuity
