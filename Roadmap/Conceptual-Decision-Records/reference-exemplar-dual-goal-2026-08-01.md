# Conceptual decision record — Three-layer delivery

Filename retained `reference-exemplar-dual-goal-2026-08-01` for continuity; **body is three-layer**, not dual-only.

## Summary

Stamp **System** (modular platform + human-usable swap/import structure), **Reference Exemplar** (Medium Fantasy default pack: campaign-capable gen + coherent graphics), and **Operator modularity** (DM pack build/swap; invite package + push) as co-primary delivery goals on the PMG. Catalog mint stays System capability altitude. Horizon demo (~30 min) is proof, not the campaign bar. Phase **6.4** is a manually minted roadmap leaf (intent + DoD pointers) — not factory start, not Half B.

## PMG alignment

Matches [[genesis-mythos-master-goal]] Delivery goals, authority/package rules, and Phase 6 three-track table. Exemplar is the **default fill** of the swap matrix, not product law.

## Alternatives and tradeoffs

| Alternative | Upside | Downside | Why not chosen |
| ----------- | ------ | -------- | -------------- |
| System-only ceiling (demo as bar) | Keeps mint thin | Erases shippable campaign default; art treated as optional debt | Rejected — Exemplar is primary secondary |
| Elevate Exemplar chrome to mint series parents | Forces UI inventory into catalog | Violates altitude; freezes one look as law | Rejected — mint addition-only |
| Exemplar freezes visuals as product law | One coherent ship skin | Blocks swap/modularity thesis | Rejected — anti-mandate |
| Modding is post-1.0 / modder homework | Defers complexity | DMs who care cannot swap packs as product path | Rejected — Operator modularity is primary |
| Players author world rules/lore via cosmetics | Faster player expression | Bypass DM/world authority | Rejected — cosmetics local; package DM-gated |
| Remine UX catalog / unlock 6.1–6.3 | Full tree rewrite | Burns locked camera dual-rail; noise | Rejected — 6.1–6.3 stay; 6.4 manual mint |

**Chosen path:** PMG three-layer + CDR + charter stub matrix + Phase 6 primary triad + manual 6.4 leaf; UX mint continues children without remine.

## Consequences

- Mint: acknowledge only; no new series parents; Exemplar graphics ≠ catalog altitude
- Phase 6.1–6.3: unchanged; 6.4 operator-authored (deepen pipeline skipped)
- Full push protocol, conflict UI, offline sync, art bible, Half B: later
- Trinity/project sync: later (vault record first)
